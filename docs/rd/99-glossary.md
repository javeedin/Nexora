# 99. Glossary
| Term | Meaning |
|---|---|
| Fusion / pod | Oracle Fusion Cloud Applications; one environment (PROD, TEST …) of a tenant |
| BIP | Oracle BI Publisher; Nexora runs read-only SQL through one deployed BIP report ("runner") and prints documents from BIP reports |
| FBDI | File-Based Data Import: Oracle's spreadsheet / CSV templates for loading data into Fusion |
| FSM | Functional Setup Manager (Fusion implementation projects, tasks, setup exports) |
| BICC | BI Cloud Connector (bulk extracts from Fusion) |
| EFF / DFF | Extensible / descriptive flexfields (customer fields on Fusion objects) |
| S2V / V2S | Store-to-van / van-to-store inventory transfers (van sales) |
| Trip | A delivery run: one lorry, one day, many orders |
| Pick release / pick confirm / ship confirm | Fusion shipping steps: create picks, confirm picked quantities, confirm shipment |
| IRN | Invoice reference number returned by a fiscal authority (e.g. MRA) |
| MRA | Mauritius Revenue Authority (e-invoicing) |
| Edge | Nexora's on-prem agent for printers, local files and private networks |
| Pack | Installable, versioned bundle of config + optional code (fiscal, analytics, rules, knowledge) |
| Data class | Sensitivity label on AI requests (public / internal / fusion-data / personal) used by the AI router |
| Interrupt | A LangGraph pause waiting for a person or the app (test, approval, apply) |
