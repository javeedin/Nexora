# Phase 0 — Foundation

Goal: a running, secure, multi-tenant platform skeleton that later modules plug into.
**Exit criteria:** sign up a tenant (vendor console or seed), invite a user, sign in with OIDC, register a Fusion pod,
run a read-only Fusion query from the web app; all of it traced, audited and tenant-isolated; CI/CD deploys to a dev
environment.
